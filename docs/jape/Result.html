    Struct Result

    Owns the PGresult via a reference count, allowing safe use with lazy ranges.

    struct Result;

    Properties

    NameTypeDescription
    affected[get] longRows touched by insert/update/delete. PQcmdTuples yields "" for commands that touch none.
    cmdStatus[get] stringThe full diagnostic string: "UPDATE 3", "INSERT 0 1", "CREATE TABLE".
    hasRows[get] boolWhether the statement returns rows (a select, or anything with returning).
    rows[get] RowsThe view. alias rows this lets the Result itself act as a range.
