    Struct Row

    One row. Also a copyable view, and it too keeps its PGresult alive.

    struct Row;

    A Row kept in GC memory — an array, a closure — holds its whole result until the GC collects it, and the GC cannot see how big that is: libpq allocates it with malloc. For large results, keep the values (as!T), not the rows.
