    Struct Connection

    Owns the PGconn. Non-copyable; the destructor calls PQfinish.

    struct Connection;

    Constructors

    NameDescription
    this (conninfo) Connects, or throws. conninfo is libpq's: "host=… dbname=… user=…" or a postgresql:// URI.

    Properties

    NameTypeDescription
    inErrorState[get] boolInside a transaction that already failed: only a rollback is accepted now.
    ok[get] boolWhether the connection is up. False after the server went away: see reset.
    preparedNames[get] string[]The names of every statement prepared on this connection.
    serverVersion[get] intThe server version as a number: 160004 for 16.4.

    Methods

    NameDescription
    copyIn (statement) Starts a COPY ... FROM STDIN, the fastest way to load rows.
    copyOut (statement) Starts a COPY ... TO STDOUT and hands back its lines, lazily.
    deallocateAll () Forgets every prepared statement, on the server and here. Use this rather than sending deallocate yourself, which would leave the two out of step.
    escapeIdentifier (s) For dynamic table/column names: $n cannot stand in for an identifier.
    exec (sql, args) Shorthand for when every value is available on the spot.
    execScript (sql) Several ';'-separated commands, WITHOUT parameters: PQexecParams accepts only one command per call, so multi-statement has to go through PQexec, which in turn has no binding. Use it for DDL and migrations, never with values coming from outside.
    isPrepared (name) Whether prepared would find something under this name.
    onNotice (handler) Where NOTICE and WARNING messages go. Without this they are libpq's problem, which means stderr — create table if not exists on an existing table is enough to produce one, so a server that never calls this ends up with someone else's log lines in its own.
    prepare (name, text) Has the server parse and plan a statement once, under a name, and keeps enough about it that prepared can hand it back later.
    prepared (name) The statement prepared earlier under this name, so it does not have to be carried around. Only names this Connection prepared are known: the :name placeholders are a client-side translation, so a statement prepared behind our back — or one from the session before a reset — cannot be recovered.
    reset () Reconnects with the same parameters. Prepared statements do not survive it, since they lived in the old session: prepare them again afterwards.
    scalar (sql, args) One value: the first column of the first row, converted to T.
    sql (text) Names a statement without running it, so its values can be bound one at a time and from different places. Nothing reaches the server until you call exec, scalar or stream on the result.
    stream (sql, args) One row at a time, in constant memory: a lazy range of T, a struct mapped by column name or Row itself. The connection is busy until the range is consumed or dropped.
    transact (work, isolation, access, attempts) Runs work inside a transaction, committing it if it returns and rolling it back if it throws — and running it again if the server says the transaction lost a race.
    transaction (isolation, access) Begins a transaction, rolled back at the end of the scope unless committed.
